## How this implementation differs from upstream

Upstream uses the libxposed API to hook SystemUI / system_server and requires root or Xposed. This project **reuses none of the hook code** and instead relies on capabilities available to any ordinary app:

| | Upstream | This project |
| --- | --- | --- |
| Sense | Hooks inside system processes | Accessibility service `getWindows()` reads window bounds |
| Draw | Hooks system UI windows | Self-built `TYPE_ACCESSIBILITY_OVERLAY` / `TYPE_APPLICATION_OVERLAY` windows |
| Act (default) | Hooks system methods | Accessibility `dispatchGesture()` replays ColorOS gesture mode's own close gesture |
| Act (optional) | Hooks system methods | Shizuku (shell identity) reads the system log for the handle's real coordinates, injects touches and runs `am` / `settings` |

Beyond that, the interaction concepts (corner summon, radial menu, app drawer, pin strips, tap-outside-to-close, swipe-up-to-close) and parts of the wording are inherited from upstream, and that attribution is not erased by rewriting the implementation path.

## Specific changes relative to upstream (per GPL-3.0 §5a)

1. A separate no-root implementation was added; **no upstream source file was modified**.
2. The application ID is `io.github.msecret.flymefreeform`, distinct from upstream's `io.github.mangi.flymefreeform`, so both apps can be installed side by side without interfering.
3. The launcher icon is generated by this project; no upstream icon asset is used.
4. Capabilities added within this project that upstream does not have: a Quick Settings tile plus automatic restoration of the accessibility toggle after boot / app update, a persistent diagnostic log (`a11y-trace.log`), and the built-in tools (screen text, screenshot, flashlight, recorder, notes, WeChat / Alipay scan and pay codes, one-tap lock).

# FlymeFreeform 图标 · 图像生成提示语包

直接复制粘贴给其它 AI 生图工具使用（Midjourney / DALL·E / 即梦 / 通义万相 / 文心一格 / Seedream 等）。

---

## 0. 使用说明

**推荐参数**

| 项 | 建议值 |
| --- | --- |
| 尺寸 | `1024x1024`（正方形） |
| 质量 | 高 / High |
| 背景 | 要**带绿底成品**选 opaque；要自己合成选 `transparent` |
| 比例后缀（MJ） | `--ar 1:1 --style raw` |

**避坑重点（务必留意）**

旧图标看起来像体重秤，根因是 **「正对的白方块 + 底部一条横条」= 秤面 + 显示屏**。所以：
- ✅ 主体用 **倾斜 / 层叠 / 悬浮 / 玻璃质感**，制造纵深
- ✅ 加一条**从角落划出的弧线**，点明「小窗从边缘呼出」的产品语义
- ❌ 不要"正对居中的白色实心方块"、不要方块底部/腰部横条

每条提示语**末尾都带了负向描述**，别删。支持独立负向词栏的平台，把「负向提示词」一栏单独填。

## 6. 微调口令（在原提示语后面追加即可）

| 想改什么 | 追加这句 |
| --- | --- |
| 换配色：蓝 | `background gradient from #4EA8FF to #1149A8` |
| 换配色：紫 | `background gradient from #A78BFA to #5B21B6` |
| 换配色：黑金 | `matte black background with soft gold (#D4AF37) accents, luxury feel` |
| 要透明底 | `isolated on a fully transparent background, no background color` |
| 更简洁 | `reduce to a single window panel only, remove the arc, even more minimal` |
| 点再拉开些 | `keep wide clear spacing between the arc and the panel, nothing touching` |
| 点改成 4 个 | `four dots evenly spaced along the arc instead of three` |
| 要更 3D | `stronger perspective tilt, deeper shadows, more pronounced depth` |
| 要更扁平 | `completely flat, no shadows, no gradients on the shapes, pure vector` |
| 加 iOS 味 | `Apple iOS app icon aesthetic, soft translucency, glassmorphism` |

## 8. 拿到图之后

生成的是 1024 位图，需要落到 Android 工程里的话：

1. 拆成 **前景（图形本体，透明底）** + **背景（绿渐变）** 两层；
2. 前景缩到画布中央约 60% 的安全区（圆形遮罩下也不能被裁）；
3. 导出 mdpi 48 / hdpi 72 / xhdpi 96 / xxhdpi 144 / xxxhdpi 192 五档 PNG；
4. 背景与前景同时写成 `drawable/ic_launcher_background.xml` 与 `ic_launcher_foreground.xml`（VectorDrawable），再在 `mipmap-anydpi-v26/` 建 adaptive-icon。
